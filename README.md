# PackVerse

Pack opening, pack battles, item deals and casino originals (Dice, Mines, Plinko,
Crash, Chicken Cross) merged with the Rarivo market — live collectible and crypto
prices, portfolio, friends and payments — behind one username/password login with
one shared wallet. Everything you pull lands in your portfolio.
One HTML file, no build step, no server.

## Running it

- **Any browser:** open `index.html`. Progress saves in the browser.
- **On the web:** double-click `deploy.command` to publish to GitHub Pages
  (`https://<you>.github.io/packverse/`). The site works offline after the first
  visit and can be added to an iPhone home screen as a full-screen app.
- **Capacitor:** copy `index.html` into the app's `www` folder.

Everything is simulated. No real money.
